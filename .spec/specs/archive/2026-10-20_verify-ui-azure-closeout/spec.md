## 5. 技术决策
- 技术栈：沿用；零新增依赖
- 证据协议：evidence: runs（机器任务 verify 由 spec_verify.py 执行；手工任务写 `verify: manual: <理由>`；verify 不得自引用本包 check 门禁）
- 本轮允许改动：默认零改动；若走查发现缺陷，修复限定在 `frontend/src/{theme,styles,layouts,views,components}/**` 样式层与图标串 + DESIGN.md
- 本轮不应触碰：后端、业务语义、引用数据流、packages/@sa/**、.env、暗色 token 数值
- Git integration branch：`spec/2026-10-20_verify-ui-azure-closeout`

### 5.1 验证策略
- 范围级别：package
- 变更对象：无预期变更；若修复则同第四轮 boundary
- 快速检查：`cd frontend && pnpm typecheck && pnpm exec eslint .`（仅发生修复时）
- 集成检查：真浏览器走查即集成检查本体
- 全项目检查：适用外：纯验证轮
- 升级触发：走查暴露跨边界回归时升级并记录
